넘겨받은 물음에 답한 곳:

- 32번 "더 깊은 설명은 혼성 오비탈(79번)": 2절 통상 표(전자쌍 수 → 혼성)와 엄밀(비공유 전자쌍이 있으면 정확한 sp³가 아님, 전자쌍 5·6개는 혼성을 쓰지 않음).
- 31번 "79번은 분자 오비탈": 3절 전체. 결합 차수가 31번의 '공유 전자쌍 수'와 맞는 것은 카드 c18 힌트.
- 63번 "2중 결합이 돌지 않음", "벤젠 전자가 고리 전체에 퍼져 있다(79번)", 카드 c08 힌트 "혼성 오비탈은 79번": 2절 엄밀·점검(π 결합 겹침), 3절 엄밀(비편재화).
- 74번 "화학은 띠를 분자 오비탈 N개의 묶음으로 본다(79번)": 연결과 카드 c25 힌트에서 이름만. 띠 자체는 74번에서 이미 배웠다.
- 72번 남은 질문 "79번이 상자 속 입자·슈뢰딩거 방정식을 받도록": 1절 직관이 상자 속 입자의 마디 $n-1$개에서 출발한다. 디랙 표기는 쓰지 않았다.

순서 통제(PRINCIPLES 2-1-1): 1~78번과 일상 지식만 재료로 썼다.
- 78번(c-spectro)은 같은 때 따로 쓰는 단원이라 내용을 재료로 쓰지 않았다. 연결에서 "분자 오비탈 사이 전자 전이는 78번 분광 분석이 다룬다"로 이름만 짚었다. 브라운 9.8의 HOMO·LUMO는 78번과 겹칠 수 있어 쓰지 않았다.
- 74번은 [[p-semicon]]으로 연결에서만. 80번 뒤 단원은 쓰지 않았다.
- 계산 화학: 연결에서 "하트리·폭, 밀도 범함수 이론"을 이름만 짚었다(우리말샘 표기 '하트리·폭 방법', '밀도 범함수 이론').
- [[id]]는 `--related` 목록 안의 p-qm, p-osc, c-bond, c-shape, p-semicon만 썼다. 30번(c-periodic), 63번(c-organic), 9번(p-wave), 78번(c-spectro)은 목록 밖이라 번호로만 불렀다.
- 쓰지 않은 것: 방사형 확률 분포와 $4\pi r^2|\psi|^2$(맥머리 5.7, 브라운 6.6 Closer Look), 90 % 경계면, 불확정성 원리 계산(맥머리 5.5, 58번에 있음), $d$·$f$ 오비탈 이름($d_{xy}$ 등, 카드 c04 힌트에 $d_{z^2}$만), 전자 승위(promotion, 카드 c15 힌트로), 공명 구조(맥머리 7.9·8.9, 앞 단원에 없음), 이핵 이원자 분자 NO의 MO 그림(카드 c18 힌트에 결합 차수 2.5만), HOMO–LUMO(브라운 9.8 Put to Work), 오존·아세트아마이드의 π MO(맥머리 8.9), 브라운 9.6의 질산 이온, 브라운 9.5의 초원자가(hypervalent) 논의 세부.
- 비유(README 5번): 쓰지 않았다. 1절 직관의 상자 속 입자와 3절 직관의 간섭은 비유가 아니라 같은 물리(정상파의 마디, 파동 함수의 중첩)다. 맥머리 5.7의 공연장 좌석(방사형 확률), 브라운 9.4의 지퍼, 9.5의 혼성 자동차·노새, 9.7의 두 바다는 옮기지 않았다. 혼성을 노새에 견주는 대비는 '두 부모의 성질이 섞인 하나'라는 점은 맞지만, 혼성 오비탈은 실제 존재가 아니라 수학적 재조합이라는 점에서 오해를 낳는다.

## 대조 (26.11.10)

- 확인한 사실
  - 양자수: 슈뢰딩거 방정식의 해 = 파동 함수 = 오비탈, 양자수 $n$·$l$·$m_l$로 특징지어짐, $m_l$은 $2l+1$개, 껍질 $n$의 오비탈 1·4·9·16개 (맥머리 5.6 표 5.2, 브라운 6.5 표 6.2와 "the total number of orbitals in a shell is $n^2$"). 껍질 원소 수 2·8·18·32 = 두 배 (브라운 6.5). 사전 '양자수'(量子數, 물리)는 네 양자수를 들고 $l$을 궤도 양자수라 부른다.
  - 다시 계산: $\sum_{l=0}^{n-1}(2l+1)$ = 1, 4, 9, 16 ($n$ = 1~4), 전자 2, 8, 18, 32. $2(2l+1)$ = 2, 6, 10, 14.
  - 수소 에너지는 $n$만으로, 다전자 원자는 $n$·$l$로 정해짐 (맥머리 5.6 그림 5.12, 브라운 6.5 그림 6.17, 마더텅 화학Ⅰ p.81). 맥머리 그림 5.12의 수소 값 −1312, −328, −146, −82 kJ/mol. 다시 계산: $-1312/n^2$ = −1312, −328, −145.8, −82.0. 58번의 $-13.6/n^2$ eV(1312 kJ/mol)와 같다.
  - $n+l$ 규칙: "다전자 원자에서 오비탈의 에너지 준위는 $n+l$이 클수록 높고, 같을 때는 $n$이 큰 쪽이 높다" (마더텅 화학Ⅰ p.81 필수개념). 다시 계산: 4s 4+0 = 4 < 3d 3+2 = 5, 3d와 4p는 둘 다 5라 $n$이 큰 4p가 높다.
  - 파고듦: 같은 껍질에서 $l$이 작을수록 원자핵 가까이 들어가 에너지가 낮음 (맥머리 5.9 grep, 30번 기록과 같음).
  - 마디: 2s는 마디 1개(공 껍질), 3s는 2개 (맥머리 5.7 그림 5.15), $n$s 오비탈은 마디 $n-1$개 (브라운 6.6 경향 2), p는 원자핵을 지나는 마디 평면 1개 (맥머리 5.7 그림 5.18, 브라운 6.6 그림 6.22), d 네 개는 마디 평면 2개의 네 잎(cloverleaf) 모양, 다섯째는 고리 두른 아령 (맥머리 5.7 그림 5.19, 브라운 6.6 그림 6.23). 마디는 정상파의 진폭 0인 곳이고 마디 양쪽은 위상(부호)이 반대 (맥머리 5.7 그림 5.16·5.18). 마디를 어떻게 건너느냐는 물음이 전자를 알갱이로 본 잘못이라는 점 (맥머리 5.7). 마더텅 화학Ⅰ p.81: "전자가 존재할 확률이 0인 지점(=마디)", 1s는 마디 없음, 2s·3s는 있음. 우리말샘 '마디면'(마디面, 물리): 주 양자수보다 하나 적은 수가 존재.
  - 마디 일반식 검산(Claude 지식, 수소 파동 함수): 전체 $n-1$ = 각 마디 $l$ + 방사 마디 $n-l-1$. 1s 0, 2s 0+1, 2p 1+0, 3s 0+2, 3p 1+1, 3d 2+0. 점검 Q(3p)의 답 2개(평면 1, 공 껍질 1)도 이것으로 셌다. 수소 2s 마디 $2a_0$ = 105.8 pm(맥머리 '100 pm 조금 넘는 곳'), 3s 마디 $1.90a_0$ = 100.6 pm·$7.10a_0$ = 375.6 pm(맥머리 본문 100·375 pm).
  - 원자가 결합 이론: 홀전자가 든 오비탈의 겹침, 같은 위상끼리 겹침, 겹침이 클수록 강함, 방향성 (맥머리 8.2 원리 세 가지, 브라운 9.4). H₂ 1s–1s, HCl 1s–3p, F₂ 2p–2p (맥머리 8.2, 브라운 9.4 그림 9.12). 우리말샘 '원자가 결합 이론'(물리).
  - 혼성: 폴링 1931, s 하나 + p 셋 → sp³ 넷 109.5°, sp³의 3은 섞은 p 수이지 전자 수가 아님 (맥머리 8.3). sp² 120°·남는 p 1개 90°, sp 180°·남는 p 2개 (맥머리 8.4, 브라운 9.5). 섞은 수만큼 생김 (브라운 9.5, 우리말샘 '혼성 오비탈' 뜻풀이). NH₃·H₂O도 sp³로 기술 (맥머리 8.3, 브라운 9.5 그림 9.18). 전자쌍 5·6개에는 쓰지 않음 (맥머리 8.4 "not a useful model", 브라운 9.5 "should not be used for hypervalent molecules").
  - σ 결합은 정면 겹침, π 결합은 옆 겹침으로 축 위아래 두 곳이 한 결합, 2중 결합 = σ + π, 3중 결합 = σ + 서로 수직인 π 2 (맥머리 8.4 그림 8.5·8.7, 브라운 9.6). π 결합이 σ보다 대체로 약함, sp·sp² 원자만 π 결합 (브라운 9.6). 에텐 6원자 한 평면 (브라운 9.6 그림 9.21). 2중 결합이 끊어져야 돈다 (브라운 9.6 레티날). 2-뷰텐 회전 240 kJ/mol (맥머리 23.5, 63번).
  - 예제 1(아세트산): 맥머리 연습 8.3과 같은 분자이고 풀이는 새로 했다. 다시 계산: 선 C–H 3 + C–C 1 + C=O 2 + C–O 1 + O–H 1 = 8, σ 7, π 1. COOH의 C는 C–C·C=O·C–O 세 방향 → sp².
  - 분자 오비탈: 분자 전체의 파동 함수, 원자 오비탈 수 = 분자 오비탈 수, 결합성(낮음)·반결합성(높음, 원자핵 사이 마디), 낮은 것부터 둘씩 (맥머리 8.7 핵심 개념 다섯, 브라운 9.7). 우리말샘 '분자 오비탈'(화학) "분포 상태를 기술하는 파동 함수".
  - 결합 차수 = (결합성 − 반결합성)/2 (맥머리 8.7, 브라운 9.7 식 9.1). H₂ 1, H₂⁻ ½, He₂ 0 (맥머리 8.7, 예제 8.9), He₂⁺ ½ (브라운 예제 9.8), NO 2.5 (맥머리 예제 8.10, 브라운 9.8). 반결합성 오비탈이 더 많이 올라가 He₂ 불안정 (브라운 9.7 각주).
  - 2주기 순서: O₂·F₂는 σ2p < π2p, N₂는 π2p < σ2p (맥머리 그림 8.20·8.22). B₂·C₂·N₂ / O₂·F₂·Ne₂로 나뉘고 까닭은 2s–2p 상호작용 (브라운 9.8 그림 9.39·9.40). B₂ 상자기성 (브라운 그림 9.40).
  - N₂ 3·반자기성, O₂ 2·상자기성(홀전자 2), F₂ 1·반자기성 (맥머리 그림 8.22, 브라운 그림 9.40). 액체 O₂가 자석 극에 붙음 (맥머리 그림 8.19, 브라운 그림 9.42). 상자기성 = 홀전자 → 자기장에 끌림, 많을수록 강함, 반자기성 = 모두 쌍 → 약하게 밀림 (맥머리 8.8, 브라운 9.8).
  - O₂ 계열 다시 계산(원자가 전자, 스크래치 `verify.py`): O₂ 12개 결합성 8·반결합성 4 → 2, 홀전자 2. O₂⁺ 11개 8·3 → 2.5, 1. O₂⁻ 13개 8·5 → 1.5, 1. O₂²⁻ 14개 → 1, 0. N₂ 10개 8·2 → 3. B₂ 6개 4·2 → 1, 홀전자 2(O₂ 순서로 채우면 0). C₂ 8개 → 2. F₂ 14개 → 1. Ne₂ 16개 → 0. NO 11개 → 2.5.
  - 예제 2 실측값: O₂ 121 pm (맥머리 표 7.1, 브라운 9.8), 498 kJ/mol (맥머리 표 7.2; 브라운 495). O₂⁺ 112.3 pm·625 kJ/mol (브라운 예제 9.9의 실측값). O₂⁻가 O₂보다 길고 약하다는 순서는 결합 차수에서 끌어냈다(맥머리 응용 8.20이 묻는 것, 수치는 쓰지 않음).
  - 비편재화: 벤젠의 sp² C 6개, 남은 p 6개의 π 결합이 고리 전체에 퍼짐, 6전자 π계 (브라운 9.6 그림 9.25·9.26). 맥머리 8.9: σ는 원자가 결합 이론, 비편재화된 π는 분자 오비탈 이론으로 함께 씀. 우리말샘 '비편재화'(非偏在化, 물리).

  - 2절 점검 답이 처음에는 σ·π 구성을 다 늘어놓았는데, 묻는 것은 회전이라 π 겹침만 남겼다.
  - '하트리-폭'을 우리말샘 표기 '하트리·폭'으로 고쳤다.
- 교과서끼리 다르거나 교과서에 없는 것
  - **한국 교과서 범위(한국 ≠ 맥머리):** 2015 화학Ⅰ(마더텅·완자)은 양자수·오비탈 모양·$n+l$ 순서·s 오비탈의 마디까지 다루고, 혼성·σ/π·분자 오비탈은 화학Ⅰ·Ⅱ 어디에도 없다(마더텅 화학Ⅱ '오비탈' 0건). 그래서 2·3절의 한국어 용어는 교과서가 아니라 사전·우리말샘과 Claude 지식(번역본 쓰임)에 기댄다.
  - **$n+l$ 규칙:** 마더텅 화학Ⅰ은 규칙으로 외우게 하고, 맥머리 5.9·브라운 7.2는 가려막기와 파고듦으로 설명할 뿐 규칙 이름이 없다. 설명은 규칙을 통상에, 까닭(파고듦)과 예외(Cr·Cu)를 엄밀에 두었다. Sc부터 3d가 4s보다 낮아진다는 것(맥머리 6.1)은 30번 기록에 있어 되풀이하지 않았다.
  - **마디 일반식:** 맥머리는 1s·2s·3s와 p·d의 그림만, 브라운은 '$n$s는 $n-1$개', 우리말샘 '마디면'은 '주 양자수보다 하나 적은 수'만 적는다. $l$개(원자핵을 지나는 면)와 $n-l-1$개(공 껍질)로 나누는 식은 교과서 본문에 없어 Claude 지식이고 위에서 검산했다. '원자핵을 지나는 면'이라 쓴 것은 $d_{z^2}$의 마디가 평면이 아니라 원뿔이기 때문이다.
  - **맥머리 5.7의 자기 모순:** 3s 마디를 본문은 100·375 pm, 그림 5.17의 'Figure It Out' 답은 330 pm으로 적는다. 수소 3s 파동 함수로 계산하면 100.6·375.6 pm라 본문이 맞다(설명에는 쓰지 않음, 영신이 번역본을 읽을 때 참고).
  - **전자쌍 세기 이름:** 맥머리는 charge clouds(전하 구름), 브라운은 electron domains, 한국 32번은 '전자쌍 수(다중 결합은 하나)'. 세는 법은 같아 32번 말을 썼다.
  - **양자수 이름:** $l$은 30번·마더텅 '방위(부) 양자수', 맥머리·브라운 angular-momentum quantum number, 사전 '궤도 양자수'(카드 c26 힌트).
  - **혼성 설명 순서:** 맥머리 8.3·브라운 9.5는 '전자 승위(2s → 2p) 뒤 혼성'으로 설명한다. 승위 단계는 실제 과정이 아니어서 설명 본문에서 빼고 카드 c15 힌트에 맥머리 설명으로 남겼다.
  - **분자 오비탈 순서의 까닭:** 맥머리 8.8은 두 그림을 주며 "계산에서 얻은 것"이라고만 하고, 브라운 9.8은 2s–2p 상호작용으로 설명한다. 엄밀은 브라운 쪽. 순서가 바뀌어도 결합 차수는 같다는 것(N₂ 두 순서 모두 3)은 스크래치에서 검산했다.
  - **결합 차수의 첫 정의:** 맥머리 7.2는 '두 원자 사이에 공유된 전자쌍 수'로 처음 정의하고 8.7에서 MO 식을 준다. 31번은 결합 차수라는 말을 쓰지 않았다. 설명은 MO 식을 정의로, 맥머리 7.2 정의는 카드 c36 힌트로.
  - **결합 에너지 값:** O₂ 맥머리 498·브라운 495, N₂ 맥머리 945·브라운 941. 31·59번이 맥머리 값을 써서 O₂ 498을 썼다. O₂⁺ 값은 브라운에만 있어 예제 2는 두 책 값을 섞었다(같은 실측 대상이라 비교에는 문제없다고 봄). 맥머리 표 7.1의 N≡N은 113 pm로 7.2 본문 110 pm와 다르다(31번은 110).
  - **벤젠 C–C:** 브라운 9.6 본문 140 pm, 브라운 24.2 표 24.1 139 pm. 63번이 139를 써서 맞췄다.
  - **π 결합 세기:** 맥머리 표 7.2의 평균값으로는 C=C 728 − C–C 350 = 378로 π가 σ보다 세 보인다(에텐의 σ가 sp²라 더 짧고 세기 때문, Claude 지식). 그래서 π의 세기는 회전 장벽 240 kJ/mol로 견주었다.
  - **$p_x$·$p_y$와 $m_l$:** 브라운 6.6 각주는 $x$·$y$·$z$ 첨자와 $m_l$ 값이 일대일로 맞지 않는다고만 한다. 설명에서는 분량 때문에 뺐다.
  - **상자기성/상자성:** 표준국어대사전·우리말샘에는 물리 용어 '상자성(常磁性)'·'반자성(反磁性)'만 있고 '상자기성'은 없다. 화학 번역서(맥머리·브라운 번역본)는 상자기성·반자기성을 쓰는 것으로 알고 있어(Claude 지식) 화학 단원인 이 단원은 그것을 쓰고, 사전 이름은 카드 힌트에 적었다. 번역본 쓰임은 영신 확인 대기.
  - **원자가 결합 이론 용어:** 우리말샘 표제어는 '원자가 결합 이론'. '원자가 결합법'도 쓰인다(Claude 지식).

## 한자

- 표준국어대사전에서 확인(26.11.10 검색): 양자수 量子數(물리), 시그마 결합 sigma結合(화학, 표제어 '시그마 결합'), 파이 결합 pi結合(화학), 상자성 常磁性(물리), 반자성 反磁性(물리), 혼성 混成('서로 섞여서 이루어짐'), 원자가 原子價(화학), 편재 偏在('한곳에 치우쳐 있음'), 차수 次數(수학), 궤도 함수 軌道函數(=오비탈). 마디는 사전에 물리 뜻이 없고 고유어다(56번에서 씀).
- 우리말샘에서 확인(사전 표제어 없음): 원자가 결합 이론 原子價結合理論(물리), 혼성 오비탈 混成orbital(물리), 혼성 궤도 함수 混成軌道函數(물리), 분자 오비탈 分子orbital(화학), 결합성 오비탈 結合性orbital(화학), 비편재화 非偏在化(물리), 마디면 마디面(물리), 하트리·폭 방법 Hartree-Fock方法, 밀도 범함수 이론 密度汎函數理論(물리). 혼성화 混成化는 우리말샘에 생명 분야 뜻(잡종 만들기)으로만 있어 한자만 맞춘 것이다.
- 구성 낱말로 맞춘 것: 분자 오비탈 이론 分子orbital理論(분자 오비탈 + 이론 理論), 결합 차수 結合次數(결합 結合 + 차수 次數, 사전·우리말샘 표제어 없음), 상자기성 常磁氣性(常 + 자기 磁氣 + 性, 사전 표제어 없음), 반자기성 反磁氣性(反 + 磁氣 + 性, 사전 표제어 없음).
- 확인 필요: 반결합성 오비탈 反結合性orbital — 우리말샘 '반결합성 궤도 함수'·'반결합 궤도 함수'는 **半**結合性으로 적었다. 같은 검색의 다른 '반결합'(되먹임) 낱말은 모두 反이고, antibonding은 결합을 '거스르는'(anti-) 오비탈이지 '반쯤 결합한' 오비탈이 아니어서 反으로 썼다. 우리말샘 쪽 잘못으로 보지만 영신 확인 대기.
- 카드 힌트의 훈(常 늘, 反 반대로, 非 아님, 化 되다, 次數 차례의 수)과 σ·π가 s·p에 해당하는 그리스 문자라는 이름의 유래는 Claude 지식이다.
- 용어 카드 c26~c39(14장). c01~c25는 정의·법칙·분류·사실 카드다.

## 올리기 전 검토 (26.11.10)

- 다시 셈: 결합 차수 H₂ 1, He₂ 0, B₂ 1(π 홀전자 2, 상자기성), N₂ 3, O₂ 2(π* 홀전자 2), O₂⁺ 2.5, O₂⁻ 1.5, F₂ 1, NO 2.5. 수소 3s 마디 r=(3±√3)·1.5a₀=100.6·375.6 pm(맥머리 본문 375 pm가 맞고 그림 답 330 pm가 틀림). 혼성 4·3·2 → sp³·sp²·sp(32번 전자쌍 수와 같음). 모두 맞다. 고칠 데 없이 올린다.
- 30번과 맞춤: 양자수 n·l·m_l·m_s는 다시 굵게 쓰지 않았다. 78번과 맞춤: 분자 오비탈 사이 전자 전이는 78번에 이름만.
