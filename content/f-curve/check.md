## 대조 (26.11.18)

- 확인한 사실
  - 최댓값·최솟값(absolute)의 정의, 정의역에 따라 달라짐($y=x^2$의 네 정의역), 극값 정리(닫힌 유한 구간·연속), 조건이 빠지면 성립하지 않는 예, 증명은 실수의 성질에 기댐 (thomas 4.1 정의·정리 1·그림 4.4).
  - 극댓값·극솟값의 정의(정의역에 드는 $x$로 견줌, 끝점은 반열린구간), 최댓값은 극값이기도 함 (thomas 4.1 정의). 상대 극값(relative extrema)이라는 다른 이름 (thomas 4.1).
  - 안쪽 점의 극값에서 $f'(c)=0$(정리 2)과 한쪽 극한의 부호로 하는 증명, 극값 후보 셋(도함수 0, 도함수 없음, 끝점), 임계점의 정의(안쪽 점, 도함수 0이거나 없음), $x^3$·$x^{1/3}$은 임계점이 있어도 극값이 없음, 닫힌구간의 최댓값·최솟값 찾는 순서 (thomas 4.1 정리 2·정의·그림 4.7).
  - 롤의 정리(조건 셋, 극값 정리로 하는 증명, 조건이 빠지면 성립하지 않는 그림), 롤의 정리 + 사잇값 정리로 근이 하나뿐임을 보이기 (thomas 4.2 정리 3·예제 1).
  - 평균값 정리(조건, 할선과 평행한 접선, $h=f-g$로 하는 증명, 끝점에서는 한쪽 연속이면 됨, $\sqrt{1-x^2}$), 평균변화율 = 순간변화율의 해석, 자동차 예 (thomas 4.2 정리 4·그림 4.16·예제 3).
  - 귀결 1·2(도함수 0 → 상수, 도함수가 같음 → 상수 차), 끝없는 구간에서도 성립, 도함수가 $\sin x$이고 한 점을 지나는 함수 찾기, 자유 낙하에서 가속도 → 속도 → 위치 (thomas 4.2 따름정리 1·2, 예제 4).
  - 귀결 3(도함수의 부호와 증가·감소, $[a,b]$에서 연속·$(a,b)$에서 미분가능), 단조(monotonic)의 정의, 임계점으로 구간을 나누고 한 점에서 부호를 봄(사잇값 정리), 끝점을 넣은 구간, 한 점에서는 증가·감소를 말하지 않음 (thomas 4.3 따름정리 3·예제 1과 그 뒤 설명).
  - 1계 도함수 판정법(연속함수의 임계점, $c$를 뺀 둘레에서 미분가능, 세 경우, 끝점은 한쪽) (thomas 4.3).
  - 증가의 정의가 엄격한 부등호인 것 (thomas 1.1 정의, f-func의 정의와 같다).
  - 아래로 볼록(concave up)은 $f'$이 열린구간에서 증가, 위로 볼록은 감소, 이계도함수 판정, 변곡점의 정의(접선이 있고 볼록이 바뀜), 변곡점에서 $f''=0$이거나 없음, $x^4$(반례), $x^{5/3}$, $x^{1/3}$(수직 접선), $x^{2/3}$(변곡점 아님), 직선 운동에서 변곡점 = 가속도 부호 변화 (thomas 4.4 정의·예제 1~6).
  - 2계 도함수 판정법(조건: $f''$이 $c$를 포함하는 열린구간에서 연속, 세 경우, 판정 실패 예 $x^4$·$-x^4$·$x^3$, 1계 판정법으로 하는 증명) (thomas 4.4 정리 5).
  - 그래프 그리기 일곱 단계(정의역·대칭, $y'$·$y''$, 임계점, 증가·감소, 변곡점·볼록, 점근선, 점 찍고 그리기) (thomas 4.4 절차).
  - 볼록의 현 정의, 미분가능하면 $f'$ 증가와 같음, 그래프가 접선 위에 놓임 (spivak 11장 부록 정의 1·정리 1~3).
  - 다시 계산한 수(Python): $x-3x^{1/3}$의 $f(-2)=1.779763$, $f(\pm1)=\mp2$, $f(8)=2$; $x^3-x$의 $[0,2]$ 평균변화율 3, $c=2/\sqrt3=1.15470$; $x^3+2x-1$의 $f(0)=-1$, $f(1)=2$; $10+\frac{1}{2\sqrt{101}}=10.04975$, $10+\frac1{22}=10.04545$, $\sqrt{101}=10.04988$; $s=1.5+19.6t-4.9t^2$; 예제 1의 $f(\pi/6)=2.2556$, $f(5\pi/6)=0.8859$, $f(2\pi)=8.2832$, $f''(\pi/6)=-\sqrt3$, $f''(5\pi/6)=\sqrt3$; 예제 2의 $f(-1)=-2$, $f(3)=6$, $f(0)=-3$, $f'$·$f''$를 수치 미분으로 확인($x=-2$에서 0.5556, $x=2$에서 8); 예제 3의 $f''=3(x+1)(x-1)$을 수치 미분으로 확인($x=-2,0,1.5,3$에서 9, $-3$, 3.75, 24).
- 고친 것: 없음(첫 초안).
- 교과서끼리 다르거나 교과서에 없는 것
  - **극값과 끝점:** 토마스는 극댓값을 '정의역에 드는 $x$'로 견주어 끝점에서도 극값을 말한다(4.1 정의, 4.1 61·77번 답이 끝점을 local max/min으로 적는다). 한국 고등학교 교과서는 '$x=a$를 포함하는 어떤 열린구간의 모든 $x$'로 정의해 극값을 정의역 안쪽에서만 말하고, 끝점의 값은 '양 끝값'으로 따로 견준다(Claude 지식). 설명은 한국 정의로 굵게 정의하고, 바로 뒤에 끝점의 비교와 '교재 문제는 끝점까지 따진다'를 적었다. 영신이 둘 가운데 하나로 통일하기를 바라면 다시 정한다.
  - **'극값'과 extreme values:** 한국어 극값은 극댓값·극솟값만 가리킨다. 토마스의 extreme values는 최댓값·최솟값과 극값을 아우르고, Extreme Value Theorem은 최댓값·최솟값의 정리다. 학습 목표의 이름대로 **극값 정리**로 굵게 썼고, 고등학교 교과서의 이름 '최대·최소 정리'를 같은 문장 뒤에 적었다.
  - **최댓값·최솟값:** 토마스는 absolute(global) maximum. 한국어는 '최댓값'만으로 쓰고 '절대 최댓값'이라고도 한다(Claude 지식). 영어 병기는 absolute maximum value로 했다.
  - **임계점:** 한국 고등학교 교과서에는 없는 말이다. 대학 교재는 critical point를 임계점으로 옮긴다(Claude 지식). 토마스는 도함수가 없는 안쪽 점까지 넣는다. 책에 따라 $f'=0$인 점만 '정류점(stationary point)'이라 따로 부르기도 하는데, 설명에는 넣지 않았다.
  - **오목·볼록:** 한국 고등학교 교과서는 '아래로 볼록'·'위로 볼록'을 쓰고 현으로 정의한다(Claude 지식). 토마스는 concave up/down을 $f'$의 증가·감소로 정의한다. 번역서는 concave up을 '위로 오목'으로 옮기기도 해서, '위로 오목' = '아래로 볼록'(∪), '아래로 오목' = '위로 볼록'(∩)이다. 대학 교재의 볼록함수(convex function)는 아래로 볼록한 함수다(spivak 11장 부록의 convex가 이 뜻). 설명은 토마스 정의로 굵게 정의하고(문제가 $f'$·$f''$으로 판정한다), 현 정의와 번역어 차이를 3절 엄밀과 카드 c18·c24에 적었다. 굵은 용어는 한국 쓰임 '아래로 볼록'·'위로 볼록'이다. f-ratio도 포물선에 '아래로 볼록'·'위로 볼록'을 쓴다.
  - **변곡점:** 토마스는 그 점에 접선(수직 접선 포함)이 있을 것을 요구한다. 한국 고등학교 교과서는 주로 미분가능한 곡선에서 볼록이 바뀌는 점으로 다룬다(Claude 지식). 꺾인 점에서 볼록이 바뀌면 토마스로는 변곡점이 아니다. 3절 엄밀에 적었다.
  - **1계·2계 도함수 판정법:** 학습 목표와 공통 안내의 이름을 따랐다. [[f-deriv|#]]는 $f''$을 '이계도함수'로 정의했으므로 본문에서는 이계도함수라 부르고, 판정법 이름에서만 '2계'를 쓰며 둘이 같다고 한 문장으로 밝혔다.
  - **단조(monotonic):** 공통 안내의 용어 목록에는 없지만 토마스 4.3 제목·정의의 말이라 굵게 더했다. 한국 고등학교 교과서는 '증가·감소'만 쓴다.
  - **도함수에서 함수 되찾기:** 토마스 4.2 31~48번이 따름정리 2로 '도함수가 주어진 함수'를 찾게 한다. 역도함수·부정적분·초기값 문제는 [[f-optim|#]]의 용어라 굵게 쓰지 않고, 귀결 2와 '미분 공식을 거꾸로 읽기' 표, 운동 예 하나로 문제가 쓰는 만큼만 실었다. [[f-optim|#]]이 같은 표를 굵은 용어로 다시 정리하면 그쪽이 체계, 이쪽이 처음 쓰임이 된다.
  - **2계 판정 실패 예($x^4$, $-x^4$, $x^3$):** 토마스 정리 5의 증명과 같은 세 함수다. 가장 짧은 반례라 그대로 두고 문장은 새로 썼다.
  - **교과서에 없는 것(Claude):** 1계 판정법에 연속이 필요하다는 반례($x\neq0$에서 $x^2$, $f(0)=1$), 정의역이 구간이 아니면 귀결이 무너지는 예 $\frac{x}{|x|}$, 열린 끝에서 극한과 견주는 규칙(연속 확장에 극값 정리를 쓴 것, f-limit의 연속 확장), 평균값 정리 부등식으로 $\sqrt{101}$ 가두기, 처음·끝 속력이 0일 때 사잇값 정리를 속력에 다시 쓰기(4.2 52번이 쓴다).
  - **넣지 않은 것:** 도함수의 사잇값 성질(다르부 정리), 극값 정리의 증명, $x\sin\frac1x$류의 극값이 무한히 많은 예는 문제(4.3 67)에 맡겼다.

## 한자

- 최댓값 最大값, 최솟값 最小값, 극댓값 極大값, 극솟값 極小값, 극값 極값 — 고유어 '값'이 붙은 혼종어. 최대·최소·극대·극소의 한자는 Claude 확인, 표준국어대사전 대조 대기. 꼴은 f-algebra의 '절댓값(絶對값)'을 따랐다.
- 임계점 臨界點, 변곡점 變曲點, 단조 單調 — Claude 확인, 사전 대조 대기.
- 극값 정리 極값 定理, 평균값 정리 平均값 定理 — 띄어쓰기는 한국어 용어를 따랐다(f-induct '數學的 歸納法'과 같은 꼴). 사전 표제어인지 모른다.
- 1계 도함수 판정법 一階 導函數 判定法, 2계 도함수 판정법 二階 導函數 判定法 — f-deriv의 이계도함수 二階導函數에 맞춘 한자. 사전 표제어가 아니다. 확인 필요.
- 롤의 정리, 아래로 볼록, 위로 볼록 — 한자 없이 영어만 달았다(f-limit '사잇값 정리'와 같은 꼴).
- 용어 카드 c26~c40(15장). 나머지 카드 c01~c25(25장, 상한).

## 그림 (4개, 앱 graph 블록)

색: 함수 c1(파랑), 할선 c2(주황, f-deriv와 같다), 접선과 도함수 $f'$ c3(초록, f-deriv와 같다), 이계도함수와 변곡점 c4(보라, f-deriv의 가속도와 같다), 임계점·최댓값·최솟값 c5(빨강), 보조선 c0(회색). 숫자는 Python으로 손잡이 처음 값과 양 끝에서 다시 계산했다.

- **그림 1 — 1절 직관 끝.** $f(x)=x^3-3x$를 $[-1.5,b]$에서 굵게, 바깥은 회색 점선. 최댓값·최솟값은 후보 $F(-1.5)$, $F(\min(b,-1))$, $F(\min(b,1))$, $F(b)$의 max·min으로 계산한다(후보가 늘 구간 안에 있게 min을 씀).
  - 손잡이 $b$: $-1.2$~2.5, 처음 1.5, 간격 0.05.
  - 다시 계산: $b=-1.2$ → 최댓값 1.872(끝점 $b$), 최솟값 1.125(끝점 $a$). $b=-1$ → 2, 1.125. $b=0.5$ → 2(임계점 $-1$), $-1.375$(끝점 $b$). $b=1.5$(처음) → 2, $-2$(둘 다 임계점). $b=2$ → 최댓값 2가 $x=-1$, 2 두 곳. $b=2.5$ → 8.125(앱은 8.13으로 보인다), $-2$.
- **그림 2 — 2절 직관 끝.** $f(x)=x^3-x$, A$(0,0)$, B$(2,6)$, 할선(기울기 3), 손잡이 자리의 접선(라벨에 기울기 $3p^2-1$).
  - 손잡이 $p$: 0~2, 처음 0.4, 간격 0.005(1.155에 선다).
  - 다시 계산: $p=0$ → $-1$, $p=0.4$ → $-0.52$, $p=1.155$ → 3.002(앱은 3으로 보인다), $p=2$ → 11. $c=2/\sqrt3=1.1547$.
- **그림 3 — 3절 직관.** 1절 통상 예의 $f(x)=x-3x^{1/3}$(앱 `cbrt`)와 $f'(x)=1-1/\sqrt[3]{x}^{\,2}$(초록 점선), 손잡이 자리의 접선과 $f'$ 위의 점, 임계점 셋(빨강).
  - 손잡이 $p$: $-3$~6, 처음 $-2$, 간격 0.05.
  - 다시 계산: $p=-3$ → $f=1.3267$, $f'=0.5193$. $p=-2$ → 1.7798, 0.37. $p=-1$ → 2, 0. $p=1$ → $-2$, 0. $p=0.5$ → $-1.8811$, $-0.5874$. $p=6$ → 0.5486, 0.6971. $p=0$이면 $f'=-\infty$라 앱이 접선·점·이음 점선을 그리지 않는다(수직 접선을 보인다).
- **그림 4 — 3절 통상(변곡점 문단 뒤).** 예제 1의 $f(x)=x+2\cos x$ ($0\le x\le2\pi$), 손잡이 자리의 접선, 변곡점 $(\frac\pi2,\frac\pi2)$, $(\frac{3\pi}2,\frac{3\pi}2)$, 왼쪽 위에 $f''(p)=-2\cos p$.
  - 손잡이 $p$: 0~6.28, 처음 1, 간격 0.02.
  - 다시 계산: $p=0$ → $f=2$, 기울기 1, $f''=-2$. $p=1$ → 2.0806, $-0.6829$, $-1.0806$(접선과의 차 $f-T$가 $x=0.2,0.6,1.4,1.8$에서 모두 음수: 접선 아래). $p=3$ → 1.02, 0.7178, 1.98($f-T$가 모두 양수: 접선 위). $p=6.28$ → 8.28, 1.0064, $-2$.
- 넣지 않은 그림: 예제 2의 유리함수 그래프(점근선은 f-limit 그림과 겹치고, 그림 넷이 상한이라 글로 남김). 롤의 정리만의 그림(그림 2의 할선이 수평인 경우라 따로 그리지 않음).
