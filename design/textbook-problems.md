# 교재 문제 설계안 (26.11.13)

교재 문제를 길에 넣는 일 전체를 한곳에 모은 문서다. 결정된 원칙은 PRINCIPLES에 있고, 두 조사의 전문은 따로 있다.

- 조사 1, 수학 단원을 넣은 새 지도: [math-path.md](math-path.md)
- 조사 2, 풀이 보조와 판정: [textbook-aids.md](textbook-aids.md)

두 조사는 서브에이전트가 했고 Claude가 검토했다. 책 본문과 문제는 옮기지 않았다. 장·절 번호와 짧은 제목만 적었다.

## 1. 정해진 것 (영신 26.11.13)

| 무엇 | 결정 | PRINCIPLES |
|---|---|---|
| 원칙 | 빠진 계단 없이, 시간보다 수련 | 0 |
| 교재 | 서웨이(2013, 9판으로 보임), 맥머리 8판 Global, 캠벨 12판 Global, 토마스(판 미정). 가진 영문판 기준 | 2-5 |
| 범위 | 연습문제 전부, 단원 숙달 조건에 넣음 | 2-5 |
| 수학 | 토마스를 같은 길 위 수학 단원으로. 따로 도는 트랙 없음 | 1 |
| 판정 | 책 답 → Claude 독립 풀이 → 재판정 → 보류(숙달을 막음) → 이의. 해설서가 있으면 참고 | 2-5 |
| 셈 | 도움 없이 첫 제출에 맞은 것만. 나머지는 하루 뒤 도움 없이 다시 | 2-5 |
| 보조 | 계산기·상수표·단위 점검은 자유. 힌트 3단계와 빠진 계단 진단. 흔들려도 위 단계를 다시 잠그지 않음 | 2-5, 3 |
| 모델 | 앱 안 호출은 가장 유능한 등급 | 5 |

## 2. 새 지도 (조사 1 요약)

- 84단원 → **114단원**. 더하는 30개는 모두 수학이다. 1단계 8, 2단계 11, 3단계 10, 4단계 1. 기존 단원 id는 그대로다.
- **큰 이동**
  1. 한 변수 미적분(토마스 1~5장)을 1단계로 내린다. 미분과 적분(`f-rate`)은 3 → 1단계, 지수·로그(`f-sci`)는 2 → 1단계. 맨 앞에 수와 식(`f-algebra`)이 온다.
  2. 파동(`p-wave`)은 1 → 3단계, 진동 뒤로 간다. 서웨이 파동 장이 단진동과 편도함수를 쓴다.
  3. 전자기와 빛(`p-electric`·`p-circuit`·`p-magnet`·`p-light`)은 2 → 3단계, 벡터 해석 뒤로 간다. 광합성·생태계도 따라 3단계로 간다.
  4. 열역학·열화학은 3 → 2단계. 2단계 화학이 엔탈피를 쓴다.
  5. 세포의 구조(`b-cell`)는 1 → 2단계, 생체 분자 뒤로 간다.
  6. 중력은 회전 뒤로 간다(각운동량).
- **단계 크기** 26 / 41 / 33 / 14. 책 문제 어림은 약 4,000 / 6,400 / 6,100 / 1,400(합 약 17,900, 센 것이 아니라 곱한 값)이다. 1단계 문제의 약 80%가 토마스다.
- **지금 지도의 빠진 계단** 수학 13건, 그 밖 15건을 찾았다(math-path.md 3절). 수학 쪽은 새 지도가 다 메우고, 그 밖은 일부만 메운다.
- 1단계 앞부분 순서: 수와 식 → 측정과 단위 → 과학적 탐구 → 비례와 그래프 → 함수 → 삼각함수 → 벡터 → 지수·로그 → 극한 → 도함수 → 연쇄 법칙 → 극값 → 최적화 → 적분 → 벡터 미분 → 운동 → 힘 → 에너지 → …

## 3. 적용할 때 함께 해야 하는 일

조사 1이 적은 것에 Claude가 검토하며 찾은 것을 더했다(★).

- **★ 단원 번호로 가리킨 곳 옮기기.** 미리 만든 설명이 다른 단원을 "(57번)"처럼 번호로 가리키는 곳이 771군데이고(83단원), 카드에도 377군데 있다. 번호는 지도를 바꾸면 달라지므로 이것이 모두 틀리게 된다. 옛 번호 → 단원 id 표(CURRICULUM)로 기계적으로 `[[id]]`(누르면 그 단원으로 가는 칩)로 바꾼다. 앞으로는 번호로 가리키지 않는다. 그러려면 `tools/content-check.py`가 `[[id]]`를 '연결' 절에서만 `related()`로 제한하게 고쳐야 한다(content/README).
- **★ 하던 단원이 잠기는 것.** 앱은 선수를 다 숙달하지 않은 단원을 하던 중이어도 '잠김'으로 보인다. `f-algebra`를 1번의 선수로 걸면, 지금 읽는 측정과 단위는 수와 식을 숙달할 때까지 잠긴다. 읽던 자리(`pos`)는 남는다.
- **새 30단원의 설명·카드.** 미리 만들어 검수하는 흐름(PRINCIPLES 5)으로 처음부터 만든다. 토마스가 없으면 수학 단원은 다른 책으로 대조해야 한다(Spivak은 드라이브에 있다).
- **바뀐 단원 다시 쓰기.** 미분과 적분, 행렬, 지수·로그, 벡터(스칼라곱·3차원), 운동(2차원), 힘(원운동), 중력, 진동, 파동, 분자 구조(혼성·분자 오비탈), 양자 화학, 원자 구조, 그리고 맡는 절이 바뀐 산·염기, 열화학, 전기 화학.
- 앱의 `N(...)` 줄(30개 추가, 선수·단계·목표 고침), 단계 설명, CURRICULUM 다시 뽑기, sources/unit-map.json(맡는 절과 대조 절 구분, 토마스 열쇠).
- **장·절별 문제 번호 범위 뽑기.** 문제 수는 아직 어림이다. 책 PDF는 이 PC iCloud Drive와 맥미니에 있다. 번호 범위만 공개 저장소(`sources/`)에 두고, 문제 글은 두지 않는다.

## 4. 문제 단계 첫 판 (조사 2의 '최소 첫 판')

- **시험할 단원:** 측정과 단위(`f-measure`, 서웨이 1장 + 맥머리 1.2~1.11). 영신이 지금 하고 있고, 토마스 없이 시험할 수 있는 첫 단원이다.
- **들어갈 것:** 문제 목록과 상태 기록, 한 줄 규칙. 책 답 비교 → 독립 풀이 판정·보류·이의. 빠진 계단 진단 1판. 따라쓰기와 하루 뒤 재풀이. 계산기(math.js)와 차원 점검. 힌트 3단계. 5문제 묶음.
- **2판으로 미루는 것:** 풀이 예제(미리 만들어 검수해야 한다), 풀이 사진 첫 오류 찾기, 공식 떠올리기, 어림, 쌍둥이 문제.
- **첫 판에서 잴 것:** Claude가 문제 사진을 제대로 읽는 비율, 보류 비율, 진단 적중, 재풀이 통과율, 힌트를 연 비율.
- 사진을 Claude에게 보내려면 앱 선언에 사진 사용을 더해야 한다(`sample: {images: true}`). 동의 창이 한 번 더 뜬다.

## 5. 영신이 정할 것과 Claude 권고

> **26.11.14 영신: "권고대로 진행".** 9번(토마스의 판)은 13판 SI Global이다. 지도는 [map-126](map-126.md)으로 적용했다.

| # | 정할 것 | Claude 권고 |
|---|---|---|
| 1 | 새 지도(수학 30단원, 큰 이동 여섯)를 적용할지 | 적용. 빠진 계단 원칙을 지키는 가장 작은 안이다 |
| 2 | 낱개 '이월 문제': 한 장 안에서 한두 문제가 훨씬 뒤 도구를 쓸 때 | 허용하되 그 도구 단원을 숙달한 바로 뒤에 푼다. 한 절 여러 문제가 그렇다면 이월이 아니라 지도를 고친다. 허용하지 않으면 역학 전체가 토마스 14장 뒤로 간다 |
| 3 | 작은 다리 단원 '벡터 미분'(성분별, 책 문제 없음)을 1단계에 둘지 | 둔다. 정의·카드·확인을 갖춘 정식 계단이다. 없으면 2차원 운동·힘·에너지가 2단계로 밀린다 |
| 4 | 수와 식을 측정과 단위의 선수로 걸지(1번이 잠시 잠김) | 건다. 1번이 과학적 표기법과 식 풀이를 쓰는데 가르친 곳이 없다. 읽던 자리는 남는다 |
| 5 | 토마스 온라인 18·19장(푸리에 급수·복소 함수)을 4단계 단원으로 | 넣는다. 양자역학·분광학이 푸리에를 쓴다 |
| 6 | 맞는 단원이 없는 책 장: 화학 열역학(맥머리 18장), 원소의 화학(21~22장), 식물(캠벨 35~39장), 생물 다양성(29~30, 32~34장) | 화학 열역학 1단원은 꼭 더한다(평형 뒤라 지금 자리가 없다). 나머지 셋도 단원으로 더하기를 권한다. 다른 단원에 붙이면 그 단원이 너무 커지고 목표와 안 맞는다 |
| 7 | 책이 없는 통계·추론·행렬·벡터 미분 | 지금은 확인 문제만으로 숙달을 본다. 통계·선형대수 책은 천천히 고른다 |
| 8 | '연습문제 전부'의 범위: 서웨이 객관식·개념 질문, 맥머리 개념·다개념 문제, 캠벨 절 끝 개념 확인, 토마스 컴퓨터 탐구 | 컴퓨터 탐구만 빼고 다 넣는다('싹 다'). 컴퓨터 탐구는 따로 프로그램이 필요하다 |
| 9 | 토마스의 판과 Early Transcendentals판인지 | 영신 답을 기다린다. 파일이 없다 |

## 6. 순서

1. 영신 결정(5절).
2. 지도 적용: `N(...)` 줄, 단원 번호 참조 옮기기, CURRICULUM. 그다음 앱 판 올림.
3. 문제 단계 첫 판을 측정과 단위로 만들고 시험한다. 장·절 번호 범위는 서웨이 1장·맥머리 1장부터 뽑는다.
4. 새 단원과 바뀐 단원의 설명·카드를 미리 만들고 검수한다. 영신이 닿기 전에 올린다(맥미니 흐름과 같이).
5. 첫 판에서 잰 것으로 보조를 고친 뒤 다른 단원으로 넓힌다.
