# 126단원 지도 (26.11.14 적용, 앱 11판)

[math-path](math-path.md)(114단원 안)를 영신이 받아들인 뒤("권고대로 진행"), 실제 책으로 다시 맞춰 적용한 기록이다. 책 본문과 문제는 옮기지 않았고 장·절 번호, 짧은 제목, 개수만 적었다. 조사는 서브에이전트 팀원 넷이 나눠 했고 Claude가 합쳐 정했다.

## 0. 결론

- 84 → **126단원**. 더한 42개: 토마스 수학 30(math-path 4절), 이산수학 5(Epp), 선형대수 3(Lang), 맞는 단원이 없던 책의 장 4(화학 2, 생명 2). 기존 단원 id는 하나도 바꾸지 않았다.
- 단계 크기: 1단계 28(1~28), 2단계 43(29~71), 3단계 37(72~108), 4단계 18(109~126). 목록은 [CURRICULUM](../CURRICULUM.md).
- 1단계 앞부분: 수와 식 → 측정과 단위 → 과학적 탐구 → 비례와 그래프 → 함수와 그래프 → 지수·로그 → 삼각함수 → 벡터 → 명제와 논리 → 증명 방법 → 집합과 함수의 정의 → 귀납법 → 극한 → 도함수 → 연쇄 법칙 → 극값 → 최적화 → 적분 → 벡터 미분 → 운동 → 힘 → 에너지 → …
- 책 문제: 토마스 8,903(센 값, 컴퓨터 탐구 뺌), Epp 약 1,500, Lang 약 370, 서웨이·맥머리·캠벨은 math-path 7-3절 어림. 전체 약 2만.

## 4. 바뀐 기존 단원

단계·선수·목표 바뀜의 전체는 앱 `N(...)` 줄과 math-path 5절에 있다. 큰 것만:

- 1단계로: `f-rate`(제목 '적분과 미적분의 기본 정리'), `f-sci`. 2단계로: `p-thermo`, `c-thermochem`, `b-cell`, `e-rock`, `e-surface`. 3단계로: `p-wave`, `p-electric`, `p-circuit`, `p-magnet`, `p-light`, `b-photo`, `b-ecology`, `c-buffer`(4→3), `e-plate`. 4단계로: `e-star`.
- 제목·목표가 바뀐 단원: `f-rate`, `f-linalg`('벡터 공간과 행렬'), `f-sci`, `f-trig`, `f-vector`, `f-stats`, `p-motion`, `p-force`, `p-gravity`('만유인력과 궤도 운동'), `p-osc`, `p-wave`, `c-atom`, `c-mole`(몰 농도, 맥머리 4.1~4.6. `c-acid`가 `c-solution`보다 앞이 되어서), `c-shape`, `c-electro`, `c-qchem`, `e-sphere`, `e-plate`.
- 앞뒤 문장 고침에서 찾아 더 고친 것: `p-thermo` ← `c-gas`(설명이 이상 기체·몰을 내내 쓴다), 미분을 가리키던 `[[f-rate]]`를 `[[f-deriv]]`로(새 지도에서 `f-rate`는 적분).
- 새 순서에서 앞뒤 말이 거짓이 된 문장 21개(14단원)를 방향 없는 말로 고쳤다. 다시 쓸 단원(위 목록) 안의 것은 다시 쓸 때 고친다.

## 5. 남은 일

1. **새 42단원의 설명·카드**(미리 만들어 검수). 영신이 닿는 순서대로: `f-algebra`(지금 1번), `f-func`(5번), 그다음 `f-logic`·`f-proof`·`f-set`·`f-induct`·`f-limit`… 
2. **다시 쓸 기존 단원**(4절의 목표 바뀐 것). 영신이 닿는 순서: `f-sci`(6번), `f-trig`(7번), `f-vector`(8번)가 먼저다. `f-rate`는 3단계에서 앞을 돌아보며 쓴 글이라 통째로 다시 쓴다. `f-linalg`는 주제가 바뀌므로 옛 카드는 `"x": true`로 두고 새 카드를 끝 번호 뒤에 붙인다.
3. **앞뒤가 뒤집힌 문장 고치기.** 새 순서에서 '~에서 배웠다/다룬다'가 거짓이 된 문장이 있다(2번의 다시 쓸 단원 밖). 방향 없는 말("자세히는 [[id|#]]")로 바꾼다.
4. **문제 단계 첫 판**(textbook-problems 4절): 측정과 단위로. 수치 적분 계산기를 더한다.
5. 맥미니: 50일 수학·완포자 특강 OCR → `f-algebra`의 문제 원천과 한국어 용어 대조. `sources/unit-map.json`에 thomas13·epp·lang 열쇠와 새 단원을 더한다. 서웨이·맥머리·캠벨의 절별 문제 번호 범위를 뽑는다.
6. Campbell 27장(`b-micro`)이 19장(`b-biotech`, 4단계)을 다섯 번 가리킨다. 27장 문제를 펼 때 확인하고, 여러 문제가 걸리면 `b-biotech`를 3단계로 내린다.
