# 과학고양 (naturegoyang)

고양 시리즈의 자연과학판이다. 한국어로 자연과학을 **마스터**하는 코스다. 목표는 지금의 과학 전체를 제대로 아는 것이고, 바닥부터 한 단계씩 단단하게 올라간다.

- 84단원 · 5영역(기초 도구·물리·화학·생명과학·지구·우주) · 4단계(기초·핵심·심화·현대). 목록: [CURRICULUM](CURRICULUM.md)
- 한 단원: 설명(직관·통상·엄밀, 한 장씩 읽기와 점검) → 암기 카드(간격 반복) → 확인 8문제(100점이어야 숙달)
- 한 단계를 모두 숙달해야 다음 단계가 열린다. '이어하기' 하나로 1번부터 84번까지 간다.

## 어디서 돌아가나

지금은 claude.ai Artifact(영신 계정, 비공개)에서 돌아간다. 설명·카드·문제를 Claude가 그 자리에서 만들고, 기록은 Artifact 저장소에 둔다. 그래서 GitHub Pages 공개판은 아직 없다. 자세한 것은 [DEPLOYMENT](DEPLOYMENT.md).

- 앱 원본: [app/naturegoyang.html](app/naturegoyang.html) (Artifact 페이지 형식이라 `<!doctype>`·`<html>` 없이 시작한다)
